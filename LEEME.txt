FloatArmors - Paper 1.20.1, Java 17.
Compilar: mvn clean package (o GitHub Actions) -> target/FloatArmors-1.0.0.jar -> /plugins
Dar: /fa give <jugador> tempestad | regalia | nucleo_vacio | <pieza>
Tempestad = base de cota de malla (CHAINMAIL), Regalia = base de oro (GOLDEN).
El resource pack reemplaza la textura de la armadura puesta de cota de malla y de oro (sin shaders, funciona con cualquier cliente).
